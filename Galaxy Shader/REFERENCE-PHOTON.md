# Photon 1.3 参数参考 · Galaxy 1.14.0

> 以下记录保留 1.14.0 的参考映射。**1.14.1 已按暖色鲜明方向重新调色**：曝光默认 1.25、饱和度 1.1，日光偏暖、天空补光更明亮且减少蓝色倾向；太阳角半径 2° 和云影强度 0.8 继续保留。当前效果与安装说明以 README 为准。

本次读取用户提供的 `photon_v1.3.zip`，以其中的默认设置和光照关系为参考，在 Galaxy 原有渲染管线内独立调整。压缩包 SHA-256：`5f96fe9becd19f56b37a740c95fe4faaadafe3e9c715d315a17ebe6600f95b3d`。参数记录见仓库 `validation/photon-parameters.json`；可用 `python tools/inspect_photon.py <Photon压缩包路径>` 重建。

| 效果 | Photon 1.3 默认值 / 行为 | Galaxy 1.14.0 对应实现 |
| --- | --- | --- |
| 太阳大小 | `SUN_ANGULAR_RADIUS=2.0` 度 | 新增同名选项，默认 2°；太阳盘与 PCSS 半影共享角半径 |
| 云影 | `CLOUD_SHADOWS_INTENSITY=0.80` | `CLOUD_SHADOW_STRENGTH=0.8`，浓云下仍保留天空补光 |
| 曝光 | `AUTO_EXPOSURE_OFF` | `AUTO_EXPOSURE=0`、`EXPOSURE=1.0`；可手动开启原有曝光适应 |
| 白平衡与调色 | 6500 K、饱和度 1、对比度 1、太阳用户 RGB 乘数均为 1 | 保留中性调色；日光颜色由太阳高度决定，不用整屏暖色滤镜 |
| 日光光色 | 太阳光经过大气透射，晨昏另有亮度与色彩补偿 | 独立的相对光程近似，正午接近白色、低太阳偏暖；保持已有低角度直射能量 |
| 天空补光 | `SH_SKYLIGHT`、`SKYLIGHT_I=1.00`，阴影内含少量反弹光 | 保留低阶方向性天空探针，调整为偏冷色，新增由天空光和 AO 限制的微弱暖反弹 |
| 低地雾 | Mie 衰减从海平面上 7 格开始，每 7 格减半 | 新增同样高度规律的低地晨雾项；以本包海平面 62 为基准，从 Y=69 开始衰减 |
| 雾密度 | Mie 清晨 0.007、正午 0.0001、傍晚 0.005 | 按 Galaxy 分析式雾与体积光的组合重新标定，避免直接叠加原值导致重复散射 |

Galaxy 的 HDR 单位、色调映射、天空模型、云影近似与 Photon 不同；阳光强度、泛光与雾密度的数字不应跨管线直接等同。此次主要对齐太阳尺寸、云影强度、固定曝光、日光与阴影色彩关系，以及低地雾的高度规律。未导入 Photon 的 GLSL、计算着色器、散射 LUT 或贴图。

`previews/photon-calibration.png` 是本次调整前后的合成 GPU 对照，左旧右新；不是 Photon 对照渲染，也不是 Minecraft 游戏截图。实际游戏中的地形、材质和天气会影响最终观感。

安装后先恢复默认设置，再选择 HIGH。已有个人配置不会因为选择 HIGH 自动重置太阳半径、云影强度或曝光开关；需要确认「光照 → 太阳角半径」为 2、「云层 → 云影强度」为 0.8、「后期 → 自动曝光」关闭。
