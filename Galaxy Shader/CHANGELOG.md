# Changelog

## 1.3.0 — 2026-09-07

- 末地行星视觉升级：四颗行星改为独立的公转速度（内圈快、外圈慢）、轨道距离与视尺寸，不再像同一模板复制；环巨星的光环按自身半径成比例绘制。
- 每颗行星新增程序化大气辉光：轮廓处最亮，向外以指数衰减为柔和尘雾，星表内侧仅在贴近轮廓的外缘保留窄辉光，不改变行星本体配色。
- 行星辉光颜色与强度按类型区分（冷蓝海洋世界、火山橙熔岩世界、琥珀环巨星、冰蓝外层行星），朝向中央恒星的一侧散射更强，形成“光从一侧溢出”的方向感。
- 重新通过完整 GPU 编译矩阵与九类合成场景离屏回归，并重跑末地天空六项夹具检查；Minecraft 游戏内验收与 FPS 实测仍待进行。

## 1.2.0 — 2026-09-07

- 性能优化：主世界云阴影从逐像素 FBM 改为逐顶点计算并经 varying 插值，减少 gbuffers 阶段重复求值；云层公共函数抽至 `lib/cloud_field.glsl`。
- 性能优化：水体透明片元先判定水体并提前结束，非水体才计算普通光照，消除原先先算后覆盖的开销。
- 性能优化：超过 60% 阴影距离后 PCF 采样数降为 4 次，配合原有远距离阴影淡出。
- 重新通过完整 GPU 编译矩阵（2,048 组入口配置 / 去重 1,014 对程序）与九类合成场景离屏回归；Minecraft 游戏内验收仍待进行。

## 1.1.0 — 2026-09-07

- 新增末地行星天空：四颗公转行星（含一颗带环巨星）、中央恒星与固定星空；运动由视线方向与时间驱动，公转/自转速度可选。
- 新增 `END_PLANETS` 与 `END_ORBIT_SPEED` 设置及「末地星空」菜单页（中英文），默认开启，仅影响末地维度。
- 以合成场景 GPU 夹具验证 6 项检查：前景遮挡不变、轨道随时间运动、速度为 0 时静止、0.5/1/2 倍速度时钟归零一致、关闭后静态、主世界/下界不受影响。
- 光影包更名为 Galaxy Shader，随包文档、构建工具与安装包命名同步更新。

## 1.0.2 — 2026-09-06

- 修复 `deferred.fsh` 中 RGBA16F、RGBA8、R11F_G11F_B10F 被当作未定义 GLSL 变量而编译失败的问题。格式声明移入多行注释，保留 Iris 的配置读取。
- 删除 GPU 验证器之前擅自补入的格式宏；增加直接展开交付源码的回归，先复现旧错误再验证修复。
- 用实际 Iris 1.10.9 与 1.11.2 的预处理器和渲染目标配置解析器确认 7 个缓冲区的格式以及 4 项清屏颜色。
- 离屏测试改用发布包声明的真实目标格式，包括 RGBA8 元数据和 R11F_G11F_B10F 泛光；重新验证全部预设与场景。

## 1.0.1 — 2026-09-06

- 修复 Iris 加载时解析 `colortex0/2/3ClearColor` 崩溃：将合法 GLSL 的单参数 vec4 简写改为 Iris 要求的四个显式分量。
- 用户日志中的复现场景是 Minecraft 26.1.2 / Iris 1.10.9 / Sodium 0.8.12；不将该崩溃归因于用户安装。
- 用实际 Iris 1.10.9 与 1.11.2 发布 JAR 验证四项清屏颜色解析及最终数值，并加入静态回归检查与打包门禁。
- 保留已有渲染效果和配置；重新运行完整 GPU 编译与离屏回归。完整游戏画面验收仍待进行。

## 1.0.0 — 2026-09-06

- 创建模块化 Iris shader pack，提供主世界、下界和末地程序入口。
- 实现自然昼夜光照、PCF 阴影、天空散射近似、程序化云与植被风。
- 实现深度水体、Fresnel、SSR/环境反射、湿润表面和 LabPBR 基础材质读取。
- 加入 AO、有限距离间接光、体积光、维度雾、HDR 泛光、Filmic、曝光和 FXAA。
- 提供可选景深/动态模糊、手持物屏蔽，以及 POTATO 至 CINEMATIC 六档预设。
- 提供中英文设置菜单、安装说明、MIT 许可与可重复打包流程。
- 使用实际 NVIDIA OpenGL 驱动编译、链接并渲染合成场景；实机游戏验收尚未执行。
