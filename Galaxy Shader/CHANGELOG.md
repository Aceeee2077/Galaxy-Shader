## 1.15.1 — 2026-10-26

- 首个 1.15 系列安装包：汇总动态银河、程序化月相与温暖日光三项开发成果；不新增菜单选项，默认值保持不变。
- 夜间银河改为随天体周日旋转的一整片动态银河：黄昏从地平线一侧升起，午夜横跨天顶，黎明在对侧落下；不再固定在空间中的破碎色块，也没有逐帧闪烁。
- 按真实宽场星空照片重建银河层次：冷蓝白星云带、暖白中央核球、分叉的暗尘带与大暗隙、少量粉色 H-alpha 区域、细密未分辨星点；全部为解析噪声，不增加纹理、查表或渲染目标。
- 银河纹理锚定在星空坐标系，整片随天球刚性旋转；地平线消光与深暮门控让它在暮光后逐渐显现。远离银道面的像素在求值噪声前提前退出，因此天空大部分区域只多一次点积。
- 银河基础亮度按默认 0.25 滑块重新标定（内部 ×1.6），独立于极光和天象事件；极光、流星、彗星和超新星强度不变。
- 新增 `tools/test_night_galaxy.py` 五项 GPU 回归（旋转、整片连续性、晨昏门控、确定性与尘埃结构）与 `tools/render_night_galaxy.py` 合成 A/B 预览；对照见 `validation/night-galaxy-report.json`，预览见 `previews/night-galaxy.png`。
- 夜晚月盘改为程序化月球：按 `moonPhase` 呈现 0–7 月相、柔和明暗界线、月海与环形山纹理和微弱地照；满月亮白，新月几乎不可见。
- 月光直射强度改为随实际受照比例缩放，新月不再保留近半满月的亮度；贴近月缘的冷色月华与宽阔天空辉光只出现在月盘附近，并随阴雨/雷暴减弱。无新增贴图、查表或渲染目标，离月球约 25° 以外的天空像素仍只多一次点积。
- 新增 `tools/test_night_moon.py` 七项 GPU 回归（确定性、昼间门控、满月/新月、相邻月相镜像、盘面边界、阴天衰减与月华）和 `tools/render_night_moon.py` 月相预览；预览见 `previews/night-moon.png`，报告见 `validation/night-moon-report.json`。
- 日光颜色改为三波段解析透射：瑞利散射（偏蓝）、米氏消光（近中性）与臭氧 Chappuis 吸收（偏绿）共同按太阳高度的相对空气质量积分。低太阳因此自然转为暖金色，臭氧抑制绿色流失，避免洋红；能量预算与原有直射强度曲线保持不变。
- 晨昏暖色带改用同一透射色，并将向阳侧 `mu` 权重由 6 次方放宽到 3.2 次方，使暖光呈现为更宽的地平线光带而非窄条；叠加后以 1.15 饱和度恢复抵消浅雾造成的去饱和。
- 太阳光晕改为 RGB 分离衰减：紧致内核红色衰减最慢、蓝色最快，外缘宽晕则蓝色衰减最慢，形成由暖核到冷边的角色分离；云层仍按原有顺序遮挡光晕。无新增纹理、查表、渲染目标或体积步进。
- 扩展 `tools/test_photon_calibration.py` 四项断言（低日暖色、暖度随空气质量增长、臭氧保持橙色、光晕外缘转冷），并新增 `tools/render_warm_sun.py` 对 1.14.1 的四场景合成 A/B；预览见 `previews/warm-sun.png`，报告见 `validation/warm-sun-report.json`。
- 完整 GPU 编译矩阵（54 项选项、2,048 组入口配置、1,062 对唯一程序）、十类场景/六档预设、全部既有单元回归、七项月相回归、扩展后的日光标定回归与 Iris 1.11.2 实际解析器检查继续通过。游戏内观感与 FPS 仍待实测。

## 1.12.3 — 2026-10-04

- 修复「晴天清晨看起来和阴天一样」的问题，原因是三处与太阳高度无关的加光/加雾：
  - **体积光**：`broadPhase` 的常数项（各向同性散射）在低太阳角度下把整个天空铺上一层暖白色，且光束对比项 `shaftContrast` 未按视线方向加权，背对太阳的天空也会被同样照亮。现在天空像素的各向同性项降到 1/8，光束按前向相位 `0.10 + 0.90·cos²` 加权；朝太阳方向的丁达尔光柱强度不变。
  - **晨昏雾**：高度雾/山谷雾的晨昏系数由 0.0038 / 0.0060 降到 0.0018 / 0.0026，雾色向暖霾混合的比例由最大 0.83 降到 0.60，晴天清晨的能见度不再被压到约四分之一。
  - **云量与遮光解耦**：`weatherOvercastAmount()` 不再把默认云量当作阴天处理（阈值由 0.38–0.66 改为 0.46–0.82，权重 0.42 降为 0.34），并把云密度阈值从 `mix(0.62,0.32)` 提高到 `mix(0.74,0.34)`，卷云权重从 0.55 降到 0.26。默认云量下天空能保留蓝天与云缝，把云量滑块推高才会得到阴天观感。
  - 大气散射的暖色带收紧为贴近地平线且偏向太阳一侧（`pow(1-h,3.5)`、各向同性份额 0.35 → 0.20）。
- 新增 `DAWN_HAZE`（大气页，0 / 0.5 / 1 / 1.5 / 2，默认 1）：缩放晨昏霾带与对应体积光。0 为通透晴天，2 恢复浓厚晨雾。
- 完整 GPU 编译矩阵（47 个选项、六档预设、ALL_OFF 与强制 PBR/动态模糊组合）、十类合成场景、参考视图、末地夹具与全部单元测试重跑通过；Iris 1.11.2 指令解析检查通过。游戏内验收与 FPS 实测仍待进行。

## 1.12.1 — 2026-09-21

  - **环境光遮蔽**：世界半径由 1.5 格改为 2.0 格（Photon GTAO_RADIUS / SSAO_RADIUS = 2.0），采样由「6 方向 × 3 步」（18 次）改为「4 切片 × 3 步」（12 次）；低档 3×2、极高 6×3、电影级 6×4。单像素 AO 采样量减少约三分之一。
  - **阴影**：PCSS 预算对齐 Photon 的「3 次遮挡搜索 + 6–12 次滤波」区间——中档 3+6、高档 4+10、极高 6+12、电影级 8+16（原中档起为 6+8 / 8+12 / 12+16 / 16+24）。每个受光片元的阴影采样从 20 次降到 14 次，代价是半影估计略粗。
  - **水体吸收**：采用 Photon 的每格吸收系数——水面水柱 0.39 / 0.14 / 0.07（红/绿/蓝），水下雾 0.20 / 0.08 / 0.04。深水不再压向黑色，水下能见度明显提高、色调更偏蓝绿。
  - **体积光**：参考 Photon 晨昏光束「地平线 20 步、天顶 4 步」的分布，视线仰角超过约 17° 后采样数减半（天顶方向积分路径短且空）。
- 与 1.12.0 的 1280×720 HIGH A/B：全屏阶段合计 -0.7%（云）/ -3.1%（日落、白天地表）/ -1.1%（雨天）/ -2.1%（水下）；水下画面平均差异 2.99/255，其余场景不超过 0.09/255。累积对照 1.11.2：云 -37.2%、日落 -37.3%、白天地表 -36.9%、雨天 -51.0%、水下 -36.6%，水面绘制本身约 -90%。

- 体积光采样同步收紧：普通介质由每档 10 次采样降为 8 次，水下由每档 4 次降为 3 次。
- 与 1.11.2 的 1280×720 HIGH 合成 A/B：云 -37.0%、日落 -37.2%、白天地表/水面 -31.9%、雨天 -47.2%、水下 -35.6%；平均 8-bit 差异 0.15–1.18、95% 分位不超过 4；水面绘制本身约 -90%。数据见 `validation/performance-report.json`，不等同于游戏 FPS。
