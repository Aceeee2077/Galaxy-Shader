# Changelog

## 1.12.1 — 2026-09-21

- 参考 Photon 1.3 的参数默认值调整了一批预算，全部为本项目自行实现的等效参数，未复制其代码：
  - **环境光遮蔽**：世界半径由 1.5 格改为 2.0 格（Photon GTAO_RADIUS / SSAO_RADIUS = 2.0），采样由「6 方向 × 3 步」（18 次）改为「4 切片 × 3 步」（12 次）；低档 3×2、极高 6×3、电影级 6×4。单像素 AO 采样量减少约三分之一。
  - **阴影**：PCSS 预算对齐 Photon 的「3 次遮挡搜索 + 6–12 次滤波」区间——中档 3+6、高档 4+10、极高 6+12、电影级 8+16（原中档起为 6+8 / 8+12 / 12+16 / 16+24）。每个受光片元的阴影采样从 20 次降到 14 次，代价是半影估计略粗。
  - **水体吸收**：采用 Photon 的每格吸收系数——水面水柱 0.39 / 0.14 / 0.07（红/绿/蓝），水下雾 0.20 / 0.08 / 0.04。深水不再压向黑色，水下能见度明显提高、色调更偏蓝绿。
  - **体积光**：参考 Photon 晨昏光束「地平线 20 步、天顶 4 步」的分布，视线仰角超过约 17° 后采样数减半（天顶方向积分路径短且空）。
- 与 1.12.0 的 1280×720 HIGH A/B：全屏阶段合计 -0.7%（云）/ -3.1%（日落、白天地表）/ -1.1%（雨天）/ -2.1%（水下）；水下画面平均差异 2.99/255，其余场景不超过 0.09/255。累积对照 1.11.2：云 -37.2%、日落 -37.3%、白天地表 -36.9%、雨天 -51.0%、水下 -36.6%，水面绘制本身约 -90%。
- 完整 GPU 编译矩阵、十类合成场景、六档预设、末地六项夹具与全部单元测试重跑通过；游戏内画面与 FPS 仍待实测。

## 1.12.0 — 2026-09-21

- 末地中央天体重做：删除「黑洞 / 虫洞」式的暗事件视界 + 光子环 + 倾斜吸积盘组合，改为**裂隙核心**——多面水晶核心、四条长衍射星芒、两道对向等离子喷流，以及两圈按角向扇区生成的碎裂石片带（每片石片独立哈希半径、厚度与色调，部分扇区留空）。整体剪影棱角分明、分段破碎，不再是圆形视界加平滑尘埃盘的构图；性能上仍是纯解析角度函数，不做逐像素积分。
- 末地其余天体改为冷紫银色系：巨行星临边辉光与行星环尘埃从暖橙改为紫银，行星受光面略带冷紫，末地环境光由偏暖改为偏冷紫，与裂隙核心的光源一致。
- 云层性能：新增按采样位置与索引决定的细节降级，march 远段只保留大尺度云团噪声并用均值替代最细八度与侵蚀层；直接天空步数改为 16 / 24 / 36（中 / 高 / 极高）；云内自阴影由三次短步距采样改为两次长步距采样，累积光路长度基本不变。云层外观差异小于 1.2/255 平均强度，云方案绘制耗时下降约 37%。
- 反射性能：水面与光滑表面的环境反射改用单层云面近似，不再为每个反射像素二次 march 体积云；屏幕空间反射步数降为 8 / 14 / 20 / 28，细化迭代减为 3 次，粗糙反射由四次轴向采样改为一次对角采样。
- 水体重做（Photon 方向）：新增 `WATER_REFLECTIONS`（仅天空反射 / 天空 + 屏幕空间），默认仅天空；水面折射由多点模糊改为一次按法线偏移的采样加最多一次附加采样；波法线最多三层；水面阳光高光由 PCSS 遮挡查询改为单次阴影采样；水下距离模糊与双层焦散只在最高水体档次运行。
- 体积光采样同步收紧：普通介质由每档 10 次采样降为 8 次，水下由每档 4 次降为 3 次。
- 与 1.11.2 的 1280×720 HIGH 合成 A/B：云 -37.0%、日落 -37.2%、白天地表/水面 -31.9%、雨天 -47.2%、水下 -35.6%；平均 8-bit 差异 0.15–1.18、95% 分位不超过 4；水面绘制本身约 -90%。数据见 `validation/performance-report.json`，不等同于游戏 FPS。
- 末地天空回归、十类合成场景、六档预设、PBR/相机组合、确定性重放、TAA 稳定与完整 GPU 编译矩阵全部重跑通过；实机验收仍待进行。

## 1.4.0 — 2026-09-12

- 新增 TAA/Temporal Accumulation：`colortex7` 持久化 HDR 历史与深度，使用前帧矩阵/相机位置进行几何与天空重投影，并加入屏幕边界、历史深度、相机切换、运动幅度和亮度差异拒绝。
- 新增 3×3 YCoCg 邻域裁剪，手部像素跳过历史累计；保留可选 FXAA。为兼容 Iris、GUI 与手部渲染，本版不启用 projection jitter，动态实体也尚无独立 motion vector。
- 阴影升级为 PCSS-like blocker search、半影估算与可变 PCF；近接触阴影更锐利，遮挡距离增大时更柔和；远距离继续自动降为 4 tap。各档编译期预算从 PCF 4 tap 到 CINEMATIC 16+24 tap。
- AO 升级为 GTAO-style 方向性地平线搜索，使用约 1.5 方块世界半径、深度重建、法线/距离边缘权重；AO 与屏幕空间颜色传递已拆分。
- SSR 加入自适应步进、距离相关厚度、二分细化、多因子命中置信度与低成本粗糙反射；miss 继续按 confidence 回退环境反射。
- 新增 Legacy Filmic、ACES-like、AgX-like 三种色调映射（默认 AgX-like），改善高光 rolloff、暗部保持与轻微夜间白平衡；自动曝光适应更慢、洞穴增益更克制，Bloom 阈值收紧。
- 体积光加入稳定像素抖动；TAA 开启时使用八帧相位变化，关闭时保持固定 pattern。
- 新增 Temporal、AO 设置页，并更新六档预设、中英文 name/value/comment、架构文档、验证器与打包版本。
